# 03 | Diseño UX/UI

**Objetivo:** hacer comprensible el flujo principal en móvil y escritorio antes de pulir pantallas secundarias.

## Documentos sugeridos

- [`metodo_diseno_de_flujos.md`](metodo_diseno_de_flujos.md): proceso repetible de BYTE-CX para investigar, mapear, prototipar y revisar flujos.
- [`plantilla_mapa_de_flujo.md`](plantilla_mapa_de_flujo.md): formato reutilizable para documentar cada flujo.
- [`mapa_piloto_consulta_a_cierre.md`](mapa_piloto_consulta_a_cierre.md): aplicación inicial del método a este producto.
- [`matriz_de_estados_y_transiciones.md`](matriz_de_estados_y_transiciones.md): propuesta de rutas y reglas para revisar las tres dimensiones de seguimiento.
- [`flujos_de_usuario.md`](flujos_de_usuario.md): tareas principales de atención y seguimiento.
- [`wireframes_y_prototipo.md`](wireframes_y_prototipo.md): bocetos textuales de baja fidelidad para escritorio y móvil.
- [`prototipo_visual/`](prototipo_visual/README.md): mockup navegable local con datos ficticios para revisar jerarquía y presentación responsive.
- [Prototipo local de construcción](../05_Construccion/prototipo_local/README.md): experimento posterior que permite probar la creación de pedidos en el navegador; usa almacenamiento local y no implementa backend/autenticación reales.
- [`contenido_y_estados.md`](contenido_y_estados.md): etiquetas, mensajes y estados de pantalla propuestos.
- [`criterios_de_accesibilidad.md`](criterios_de_accesibilidad.md): criterios para que los flujos sean utilizables.
- [`prueba_de_uso.md`](prueba_de_uso.md): guion preparado para probar el prototipo cuando haya participantes.

## Estado actual

Los documentos son propuestas iniciales construidas a partir del brief, escenarios sintéticos y patrones publicados de productos existentes. No son requisitos aprobados ni resultados de investigación con comercios. La [ronda 01 de descubrimiento](../01_Descubrimiento/ronda_01_mapeo_as_is.md) está preparada para reconstruir primero el proceso actual con tiendas de tecnología; después se revisará el prototipo.

El prototipo visual ayuda a discutir distribución, etiquetas y próximos pasos. No modifica la etapa del proyecto: sigue siendo una propuesta previa a la validación con comercios. El flujo para crear y revisar estos artefactos está en [Entorno y herramientas: diseño UX/UI](../../../../08_Entorno_y_Herramientas/02_Herramientas_de_Industria/diseno_ux_ui_y_prototipos.md).
